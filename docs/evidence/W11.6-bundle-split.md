# W11.6 · Web bundle split

2026-10-13 · Opus 5.5 · v0.2 track A batch 3 (R9)

Vite's 500 kB chunk warning is gone. Two changes:

1. **Heavy catalog blocks load on first use** (`apps/web/src/catalog/lazy-block.tsx`): Layers and
   ClaimCard, FindingChart, BeforeAfter, StartHere, Gallery (with its lightbox), FileView and
   DecisionBlock each come in their own chunk. Until a chunk arrives the block's panel shows a calm
   skeleton (`catalog/skeleton.tsx`, still under reduced motion). Once the first page has shown,
   the browser fetches them in idle time, so a later page with a chart doesn't wait. Tests preload
   every block (`vitest.setup.ts`), so a render shows them at once, as before.
2. **Libraries in their own chunks** (`apps/web/vite.config.ts`): React, the router, Markdown,
   icons and `@pharos/schema` (with zod). They change less often than the app, so they stay cached
   across updates.

| main before batch 3 (one chunk)                    | 944.0 kB      | 944.0 kB (276.8 kB gzip)          | yes     |

The lazy blocks add up to 59.2 kB (21.6 kB gzip), loaded only when a page uses them or in idle
time. The first load is not slower: it is slightly smaller, and the seven files load in parallel
(Vite adds `modulepreload` links for them).

Not done: splitting the Settings page or the file drawer off. They are small next to the
libraries, and the drawer opens from almost every page.
