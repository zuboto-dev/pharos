2Problems it turned up

To write the tests, the models read Pharos closely and found these five problems. None is fixed yet.

What's really blocked or late
Order lighting materialsQueued · due 6 Oct

Why it matters: Pharos gives this example to agents as a pattern to copy, so their views can warn you about cancelled work.

What happens next: not fixed. The suggestion is to fix it after the first results, so the test can show the difference. That's one of the questions for you.

An empty list says 'No tasks yet' when there are tasks

Illustration, on the practice project 'Catalog delivery'

What is true
Foundation has 2 tasks, both finished: 'Define catalog data shape' and 'Record baseline import'. The honest message is 'Nothing matches'.

Why it matters: it tells you a phase is empty when it is actually finished.

What happens next: not planned yet. Whether to require 'Nothing matches' is one of the questions for you.

What happens next: planned in a later stage (letting you adjust views yourself), paused.
