# Catalog fixture

`dataset.json` is a static test fixture with synthetic people and a generic repository path.
It captures a mix of task and stage states so rendering, filtering, editing, and history tests
have stable inputs. Its milestone statuses and dates are test cases, not Pharos's current plan.
It is not loaded into the application as a seed.

Keep additions synthetic. Do not replace this file with a database export or real project data.
